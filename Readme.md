# MERN E-commerce Backend

This is a Node.js backend for a full-stack E-commerce application built with the MERN stack. It uses Express.js, MongoDB (Mongoose), JWT-based authentication, and Zod for validation.

---

## Features

- User authentication with JWT and bcrypt password hashing
- Product management (CRUD)
- Shopping cart with add/remove functionalities
- Order placement and order history retrieval
- Robust validation using Zod schemas
- JWT-protected routes with role-based access
- Centralized error handling and validation middleware

---

## Tech Stack

- **Node.js**  
- **Express.js**  
- **MongoDB** with Mongoose  
- **JWT** for authentication  
- **bcrypt** for password hashing  
- **Zod** for request validation  
- **dotenv** for environment variables  
- **cors** and `express.json()` middlewares
